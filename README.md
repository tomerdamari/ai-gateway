# FireGate

שער אחד שכל השימוש בבינה מלאכותית בחברה עובר דרכו: עובדים בצ'אט, ואפליקציות דרך מפתח. השער יודע מי שואל, מה מותר לו, כמה הוא והצוות שלו כבר הוציאו החודש, מסתיר מידע רגיש לפני שהוא יוצא לספק, ורושם הכל. מפתחות הספקים (Anthropic, ‏OpenAI, ‏Google) נשארים על השרת של החברה.

**הדגמה חיה:** https://tomerdamari.github.io/firegate/ (ניהול) · [צ'אט](https://tomerdamari.github.io/firegate/chat.html) · [תיעוד](https://tomerdamari.github.io/firegate/docs.html)
ההדגמה היא אתר סטטי: אותם מסכים עם נתוני דוגמה, בלי שרת. שינויים לא נשמרים והצ'אט עונה תשובה קבועה. בונים אותה מחדש עם `python pages/build.py` ומעלים את `pages/site` לענף `gh-pages`.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/tomerdamari/firegate)

**הדגמה בלחיצה:** הכפתור מקים שרת חינמי ב-Render עם נתוני דוגמה. סיסמת המנהל וסיסמת משתמשי הדוגמה נוצרות אקראית ומופיעות בלוח הבקרה של Render, בלשונית Environment. בתוכנית החינמית השרת נרדם אחרי 15 דקות בלי ביקורים, והנתונים מתאפסים בכל הפעלה מחדש. לשימוש אמיתי צריך שרת עם דיסק קבוע.

## מה יש בו
- **צ'אט לעובדים** (`/chat`): בחירת מודל או "אוטומטי", שיחות שמורות עם ארכיון, חיפוש במסמכי החברה, ותקציב שנשאר.
- **מסך ניהול** (`/`), מסודר כמו התפריט שלו:
  - **לוח בקרה** ו**לטיפול**: הוצאה, צפי, גרפים, צעדים ראשונים, התראות (תקציב, נעילות, מפתחות, הוצאה חריגה, ספק איטי) והמלצות לחיסכון.
  - **משתמשים ומפתחות**: תקציב, מגבלת בקשות לדקה, מכסת טוקנים ליום, מודלים מותרים, סיסמה לצ'אט ומפתח API עם תאריך תפוגה. לחיצה על שם פותחת מסך עם כל הפעילות של המשתמש.
  - **מודלים**: Claude, ‏GPT, ‏Gemini ומודלים על שרת של החברה (Ollama או vLLM), בשמות האמיתיים שלהם. מחירים, מודל גיבוי, בחירה אוטומטית בין זול לחזק, מטמון אצל הספק ומעקב מהירות.
  - **צוותים**: תקציב צוות, מודלים מותרים לצוות, ומרכז עלות לחיוב פנימי.
  - **מקורות מידע**: קבצים, תיקייה בשרת ושרתי MCP, עם הרשאה לפי צוות וחיפוש לפי מילים ולפי משמעות.
  - **דוחות**: חודשי לפי צוות, משתמש ומודל, קובץ חיוב פנימי, וסיכום חודשי במייל להנהלה.
  - **אבטחה**, **לוג טוקנים**, **יומן שינויים** חתום, ו**ארכיון**: שום דבר לא נמחק, הכל עובר לארכיון ואפשר לשחזר.
- **אפליקציות:** מקבלות מפתח משלהן ועובדות דרך השער בדיוק כמו מול הספק (`/v1/messages`, `/v1/chat/completions`).
- עברית ואנגלית, ומצב כהה.

## הרצה
```bash
cp .env.example .env          # ממלאים את מפתחות הספקים, ואם יש דומיין גם SITE_ADDRESS
docker compose up -d --build
```
בלי Docker: `pip install --require-hashes -r requirements.txt` ואז `python gateway.py` (עולה ב-`http://localhost:8080`).
נתוני דוגמה: `python seed_demo.py`. בדיקות מול ספקים מדומים, בלי כסף אמיתי: `python test_gateway.py`.
